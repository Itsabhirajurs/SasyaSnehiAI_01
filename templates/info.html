About Sashyasnehi AI

An intelligent, open-source crop advisory system for Indian farmers — built with transfer learning, real-time weather data and multilingual AI.

Project Overview

Sashyasnehi AI (meaning "Friend of Crops" in Odia) is a modular web-based advisory system that combines deep learning plant disease classification with contextual environmental risk, chemical safety analysis, and multilingual AI guidance. The goal is to put expert-level crop health analysis into the hands of every farmer — for free, in their language, with no technical knowledge required.

Technology Stack

Python 3.12 Flask 3.1 TensorFlow 2.18 MobileNetV2 Keras OpenCV HSV Google Gemini API OpenWeather API Pillow Vanilla JS CSS Grid Jinja2

AI Model Architecture

The disease classifier uses MobileNetV2 as a frozen feature extractor (pretrained on ImageNet), with a custom classification head:

  • INInput: 224x224 RGB leaf image, preprocessed with MobileNetV2 normalisation
  • BKBase: MobileNetV2 frozen (87 layers, 2.2M params) — ImageNet weights
  • HDHead: GlobalAveragePooling2D → Dropout(0.3) → Dense(128, ReLU) → Softmax(N)
  • TRTraining: Adam (lr=1e-4), categorical crossentropy, EarlyStopping + ReduceLROnPlateau
  • CLClasses: Tomato Early/Late Blight, Potato Early/Late Blight, Pepper Bacterial Spot, Tomato Healthy

System Modules

  • 01model_loader.py — Singleton TF model service, loads once, serves predictions
  • 02severity.py — HSV colour masking: yellow + brown + dark ranges → infected pixel percentage
  • 03weather.py — OpenWeather free-tier API: humidity, temperature, rain probability risk formula
  • 04chemical_safety.py — JSON knowledge base lookup: bee toxicity, soil microbe impact, human health risk
  • 05advisory.py — Rule-based engine: severity x risk x soil type → actionable treatment plan
  • 06llm_service.py — Google Gemini with auto-failover across 34 available models; offline fallback mode
  • 07app.py — Flask orchestration layer: routes, image save, module pipeline, JSON chat endpoint

Supported Crop Diseases

T-EB

Tomato Early Blight

Alternaria solani — dark concentric rings on lower leaves.

T-LB

Tomato Late Blight

Phytophthora infestans — water-soaked lesions, white mould.

P-EB

Potato Early Blight

Alternaria solani — brown target-board spots on foliage.

P-LB

Potato Late Blight

Phytophthora infestans — dark patches, rapid defoliation.

C-BS

Pepper Bacterial Spot

Xanthomonas euvesicatoria — water-soaked leaf spots.

OK

Tomato Healthy

No disease detected — confirms a disease-free leaf image.

Data & Privacy

Uploaded images are stored locally in static/uploads/ and are not transmitted to any external server. Location data (if provided) is used only for a single OpenWeather API call during the analysis request and is not stored. API keys are kept in a local .env file and never exposed in the browser.
